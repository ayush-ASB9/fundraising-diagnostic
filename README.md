# Fundraising Diagnostic

A website designed to help founders assess their fundraising readiness.

The site walks through key aspects of a potential raise and surfaces areas that may need more attention before approaching investors.

## What you'll find

- Fundraising readiness assessment
- Key areas to evaluate before raising
- Potential gaps and weak points
- Actionable observations for founders
